# Develop Ghana Lab – Architecture Status

**Last updated:** 2026-07-25

- Next.js 15 App Router + TypeScript
- Tailwind CSS + custom design system (Ghana brand colors)
- Root layout with Poppins + Open Sans
- Responsive Navbar + Footer
- Dark mode (next-themes)
- Public pages: Home, Blog, Shop, About, Contact
- Loading, Error, and Not-Found pages
- Utility helpers and UI primitives (Button, Card, Spinner)
